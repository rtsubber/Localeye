Privacy Policy

Last updated: June 16, 2026

Local-Eye API ("Local-Eye", "we", "us") operates the website localeye.co and the API at api.localeye.co. This policy explains what data we collect, why, and how we handle it.

Chrome Extension

The Local-Eye Chrome Extension ("Scam Shield") additionally collects:

  • Current page URL — sent to our API only when you click "Verify This Site" (never automatically on the free tier)
  • Playground tokens — temporary session tokens for rate limiting, expire after 1 hour
  • Daily check count — stored locally in your browser, reset at midnight

The extension does not automatically send URLs or track browsing history. On the free tier, checks are initiated by you. The Pro tier's "Background Protection" feature checks new pages only after you explicitly enable it.

What We Collect

Account Information

When you sign up, we collect:

  • Email address — used for account identification and important notifications
  • API key — automatically generated for API authentication
  • Signup IP address — used for abuse prevention and rate limiting

API Usage Data

When you make API calls, we log:

  • Endpoint called — which API method you used
  • Timestamp — when the call was made
  • Response status code — success or error
  • Response time — for performance monitoring

We do not permanently store the full content of API responses. Response content is held in memory during request processing and discarded afterward. We retain only the metadata listed above.

URLs You Submit

When using our verification endpoints, you provide URLs for us to check. We process these in real-time on a residential IP and return the results to you. We do not build a database of URLs checked by users.

Phone Numbers You Submit

Our phone verification endpoint calls phone numbers you provide. We log the call outcome (answered, voicemail, scam detected) for the purpose of returning results to you. We do not retain call recordings or transcripts beyond 30 days.

Why We Collect This Data

  • Abuse prevention — Rate limiting, fraud detection, and protecting the service from misuse
  • Service improvement — Understanding usage patterns to build better features
  • Billing — Tracking API usage against tier limits
  • Security — Detecting and responding to unauthorized access

Data Retention

  • Account data — Retained until you delete your account
  • API usage logs — Retained for 90 days, then aggregated into anonymous statistics
  • Phone verification results — Retained for 30 days, then deleted
  • Sign-up IP addresses — Retained for abuse prevention; deleted with your account

Data Sharing

We do not sell, rent, or share your personal data with third parties. We may share data only:

  • With your explicit consent
  • To comply with legal obligations
  • To protect our service from fraud or abuse

Security

We take reasonable measures to protect your data, including:

  • All API traffic is encrypted via HTTPS/TLS
  • API keys are hashed — we cannot retrieve your original key if lost
  • Database access is restricted to authorized systems
  • Infrastructure runs on isolated, regularly patched servers

Your Rights

  • Access — You can request a copy of your data at any time
  • Deletion — You can delete your account and all associated data by emailing support@localeye.co
  • Data portability — You can export your usage data in JSON format

Third-Party Services

Local-Eye uses the following third-party services:

  • Cloud infrastructure — For hosting and API delivery
  • Payment processing — Stripe (we never see your full card number)

Changes to This Policy

We may update this policy from time to time. Material changes will be communicated via email to registered users. Continued use of the API after changes constitutes acceptance.

Contact

Questions about this policy? Reach us at support@localeye.co
